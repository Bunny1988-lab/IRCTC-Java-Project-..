# Database Scripts & Migrations

This directory contains database DDL and DML scripts for the IRCTC Railway Reservation System.

## Contents
- SQL scripts for creating schema tables, constraints, foreign keys, and indexes will be placed here in upcoming tasks.
- Sample seed data for stations, trains, routes, and coaches.

## Note
Do not commit raw database credentials or environment files to version control.
Use `src/main/resources/db.properties.example` to configure your local MySQL database.
